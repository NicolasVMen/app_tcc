Estas cópias partem da revisão corrigida pelo orientador e acrescentam os dois
ciclos de autonomia acompanhados até a parada observada, os controles locais
para emergência sem resposta da placa e os testes da oficial 1.0.5. O texto
separa a descarga real do ensaio posterior com Bluetooth desligado; não afirma
que a descarga completa foi repetida na versão 1.0.5. Foram conferidos o texto
dos PDFs (46 páginas cada) e os números do sumário e das listas após exportação.
**Ainda não há aprovação do orientador para substituir a versão no Drive.** O
arquivo recebido dele e os rascunhos intermediários permanecem no computador,
fora deste repositório.

## Fontes mantidas

O modelo institucional, o projeto de pesquisa e as imagens-fonte da revisão
continuam nesta pasta para consulta. Capítulos avulsos, cópias de 04/11/2026,
verificações geradas e scripts específicos daquela revisão foram retirados do
GitHub por estarem superados pela cópia acima. Permanecem no computador e
podem ser recuperados pelo histórico do Git.

O documento atual ainda depende do parecer do orientador. Não é declaração de
homologação, patenteabilidade ou conformidade normativa integral.
