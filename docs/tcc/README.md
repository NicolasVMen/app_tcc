projeto de pesquisa e template são fontes históricas; não representam a
revisão atual. Permanecem preservados. A cópia original do Word do Drive
foi salva em `backups/tcc/2026-11-04/` e também duplicada na pasta do Drive
antes da atualização, sem alterar os arquivos do 9º semestre.

Ferramentas locais de reprodução: `tools/atualizar_tcc_2026_11_04.py`,
`tools/renderizar_tcc_word_2026_11_04.ps1` e `tools/conferir_pdf_tcc_2026_11_04.mjs`.
O gerador depende da fonte original identificada; não o executar sobre uma
revisão manual posterior sem antes comparar as alterações. O script Word
gera artefatos; não envia arquivos ao Drive ou GitHub automaticamente.
