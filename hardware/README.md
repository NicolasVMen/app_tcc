# Hardware

O diretório `case_3d/` reúne o projeto paramétrico da caixa vestível, a
auditoria dimensional e os arquivos atuais para impressão.

Para uma nova impressão, utilizar somente os STL de
`case_3d/PARA_IMPRIMIR_AGORA/`. Versões antigas e arquivos de verificação são
mantidos localmente em pastas próprias e ignorados pelo Git.
