# Hardware

O diretório `case_3d/` reúne o projeto paramétrico da caixa vestível, as
ferramentas de verificação e os arquivos atuais para impressão.

Para uma nova impressão, utilizar somente os STL de
`case_3d/PARA_IMPRIMIR_AGORA/`. Versões antigas foram retiradas do GitHub;
continuam na cópia local e podem ser recuperadas pelo histórico do Git.
