# Arquivos para a nova impressão

Enviar somente estes três arquivos STL:

1. `01_base_v2_4.stl` — uma unidade.
2. `02_tampa_v2_4.stl` — uma unidade.
3. `03_trava_C_v2_4.stl` — preferencialmente duas unidades, pois a peça é
   muito pequena e a segunda serve como reserva.

O prolongador do botão que já foi impresso será reutilizado e não deve ser
impresso novamente.

Orientação prevista:

- base com o fundo apoiado na mesa;
- tampa com a face externa plana apoiada na mesa;
- trava C deitada com a face maior apoiada na mesa.

Esta pasta contém a revisão atual. Não utilizar os arquivos guardados em
`historico`, `verificacoes` ou `extras_nao_enviar`.
