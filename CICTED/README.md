# Cópias de entrega e anotações do CICTED

Estes quatro arquivos foram preservados no caminho que o usuário já utiliza.
Não são código do aplicativo nem documentos do TCC.

Existem versões de nomes iguais em `docs/cicted/banner/impressao`. Algumas
são idênticas, mas os PowerPoints EQUILIBRADO e REVISAO_2 têm diferenças.
Por isso, nenhuma versão foi apagada, mesclada ou declarada final apenas pelo nome.

O banner EQUILIBRADO desta pasta também é entrada dos scripts de inspeção e
correção do parecer. Mover a pasta quebraria esses caminhos.

Para localizar resumos identificados/anônimos e outras revisões, consultar
[documentação](../docs/README.md) e [índice dos banners](../docs/cicted/banner/README.md).
